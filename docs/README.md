# Dokumentasi ANABUL

Dokumen di folder ini adalah sumber kebenaran proyek: kalau kode dan dokumen berbeda,
dokumen yang menjelaskan maksudnya dan kode yang harus diperbaiki (atau dokumennya diperbarui
di pull request yang sama).

Semua dokumen ditulis dalam bahasa Indonesia karena aplikasinya untuk pengguna Indonesia.
Ringkasan bahasa Inggrisnya:

| Dokumen | Isi |
|---|---|
| [PRD.md](PRD.md) | Product requirements: goals, user stories, acceptance criteria, non-goals |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Stack, build pipeline, deployment, environment variables |
| [DATA_MODEL.md](DATA_MODEL.md) | Database schema, tables, and relations |
| [API.md](API.md) | REST endpoints, request/response shapes, error codes |
| [AGENT_TOOLS.md](AGENT_TOOLS.md) | Agent design, the 14 tools, confirmation flow for risky actions |
| [UI_SPEC.md](UI_SPEC.md) | Mobile UI spec: palette, typography, mascot, motion levels, copy rules |
| [ROADMAP.md](ROADMAP.md) | Phased plan and what is done |
| [DECISIONS.md](DECISIONS.md) | Decision log: what was decided, why, and open questions |

Working rules for contributors (human or AI agent) live in [../AGENTS.md](../AGENTS.md).
